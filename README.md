Entry for the make.fun bounty **"The Funniest Honest Appliance Error"** — a deadpan
appliance engineer judges the funnier honest error message.

## The entry

> Error 12: unbalanced load. One wet towel, 14 socks, 214 warnings ignored. I am walking across the kitchen floor now. Catch me if you can.

A washing machine, fed up after 214 ignored warnings, gives up on spinning and
walks across the kitchen floor instead. Honest fault (unbalanced load), real
twist (the machine leaves), flat put-upon voice, 137 characters.

## Run

```sh
node main.ts
```

Writes the entry line to `/output/entry.txt` (validated: 1–200 chars, not only
whitespace) before writing.
